# Flavoria 🍔✨

Flavoria is a modern food delivery app prototype designed to deliver a smooth and visually engaging experience for discovering, ordering, and enjoying delicious meals online.

---

## 🚀 Features

* Modern UI/UX Design
* Smooth Food Browsing Experience
* Interactive Food Categories
* Clean Mobile App Layout
* Fast & Simple Ordering Flow
* Modern Color Palette & Typography
